# AI 助手

[English](assistance.md) | **简体中文**

## 使用方式

打开侧栏的 **AI 助手**。在本机运行 [Ollama](https://docs.ollama.com/)，通过
`OLLAMA_NO_CLOUD=1` 关闭其云端功能，并安装支持
[结构化输出](https://docs.ollama.com/capabilities/structured-outputs)的本地模型。
在**本地模型设置**中保存模型名和 Ollama 端口（默认 `11434`）。应用不会安装模型。

输入请求，或留空获取一般任务建议，然后点击**生成建议**。生成在工作线程运行，
导航和日常功能仍可使用。没有启动请求、定时请求或自动执行。

每张卡片展示建议理由、操作与目标记录。点击**确认并执行**应用已保存的预览，
点击**拒绝**忽略建议，或点击**编辑建议**修改字段。**保存预览**只更新建议，
执行仍须单独点击**确认并执行**。待确认建议在导航和重启后保留。

## 支持的操作

| 类型 | 字段 | 确认后的效果 |
| --- | --- | --- |
| `createTodo` | `title` | 创建进行中的任务 |
| `completeTodo` | `todoId` | 完成已有进行中任务并记录 `completed_at` |
| `setTodoTags` | `todoId`、`tagIds` | 替换任务标签，同时更新关联和 id 缓存 |
| `renameTag` | `tagId`、`name` | 重命名已有标签，保持名称大小写不敏感唯一 |
| `createAlarm` | `label`、`hour`、`minute` | 在下次到达该本地时间时单次提醒，沿用闹钟默认设置 |

优先级建议通过理由表达，本功能不引入任务优先级或截止日期字段。
模型被要求仅在用户请求有明确依据时建议完成任务，每个操作仍须用户审阅。

## 数据流与校验

`AssistancePage` / `AiSuggestionCard` → `assistanceStore` → `assistance_commands` →
`services/assistance`（推理）/ `models/assistance`（审阅与执行）→ SQLite。

仅向模型提供至多 200 条任务（未完成优先、最新优先）、100 个标签的快照与用户请求，
不包含应用历史和窗口标题。HTTP 请求固定发往 `http://127.0.0.1:<port>/api/chat`，
禁用代理与重定向，拒绝云端模型名称。请按上述方式使用本地模型并关闭 Ollama 云端功能。
常规功能无需 Ollama。模型不可用或响应无效时显示可恢复的错误，不修改业务数据。

模型通过固定的五种操作白名单返回 JSON 建议，每次至多六条，总计至多 100 条待确认建议。
拒绝未知操作/字段、空白或超长文本、非法时间以及不在模型上下文中的 id。
失败批次不会留下部分建议。请求超时为 120 秒，响应上限为 128 KiB。

建议保留推理时目标的实际值。推理期间数据变更会使整批建议失败，之后变更则阻止确认。
保存编辑会捕获当前目标并递增版本号。确认命令只接收已存建议 id、审阅的版本和
`confirmed: true`，不接收替代操作。重复或旧版本确认无法再次执行。
业务变更、终态和确认日志处于同一 SQLite 事务，任意失败都会全部回滚。

## 操作日志

页面按最新优先展示提议、编辑、确认和拒绝记录，包含理由、操作负载、按当前语言显示的
UTC 时间戳、建议 id，以及成功操作影响的记录 id。原始与编辑后的负载分别留痕。
历史目标使用 id 展示，避免后续改名/删除改写历史操作的显示含义。
支持游标分页，每页 50 条，可加载更早记录。

**清空日志**通过内联确认删除审计记录和已处理建议行。
任务、标签、提醒和待确认建议保留，清空不会执行或撤销操作。

## 验证

运行 `pnpm lint`、`pnpm build`、`cargo fmt --check`、`cargo clippy -- -D warnings` 和
`cargo test`（Cargo 命令在 `src-tauri/` 运行）。Rust 测试覆盖本地 HTTP 模型替身、
非法响应、推理期间数据变更、显式确认、编辑、拒绝、重复/并发确认、标签一致性、
日志失败回滚、重启持久化、清空与分页。

界面测试先运行一次 `pnpm exec playwright install chromium`，再运行 `pnpm test:ui`。
测试使用 IPC 替身，无需真实模型。真实模型验收时，在桌面应用中连接本地 Ollama 模型，
依次生成、编辑/保存、确认/拒绝、重启和清空日志，并验证推理期间任务和闹钟仍可使用。

任务快照包含截止日期和循环元数据。修改截止日期或跨越循环周期边界后，必须重新审核，助手不能用旧预览完成另一个周期的任务。AI 页面同样可在侧栏拖拽编辑窗口中调整。
